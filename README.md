# ⚡ TurnoSimple

> **Menos citas perdidas.** Sistema inteligente de gestión y recuperación de turnos en tiempo real para profesionales independientes, barberías, salones y estudios.

---

## 📌 ¿Qué es TurnoSimple?

TurnoSimple resuelve el mayor problema de los negocios basados en citas: el **ausentismo y los horarios cancelados a última hora**. 

Permite que los clientes reserven turnos en segundos y, si un turno se cancela o el cliente no asiste, el horario se libera inmediatamente para ser reasignado a clientes en **lista de espera**.

---

## 🚀 Características Principales

- **📅 Agenda Interactiva en Tiempo Real:** Visualización semanal de horarios disponibles, ocupados y pendientes de confirmación.
- **⚡ Recuperación de Turnos Liberados:** Detección de cancelaciones con aviso prioritario a la lista de espera.
- **💳 Simulación de Señas y Pagos:** Cobro de anticipos por tarjeta, QR o transferencia para reducir ausencias.
- **👥 Roles de Usuario:**
  - **Cliente:** Explora locales, consulta disponibilidad y reserva turnos.
  - **Dueño de negocio:** Panel de administración para crear y gestionar horarios, locales y servicios.
- **📍 Geolocalización y Búsqueda:** Encuentra locales cercanos por nombre, tipo o ubicación GPS.
- **☁️ Sincronización Híbrida:** Conexión en la nube con Cloud Firestore y respaldo automático en almacenamiento local (`localStorage`) para operar siempre sin interrupciones.
- **🎨 Diseño SaaS 2026:** Interfaz estética *Obsidian Glassmorphism*, fluida, moderna y 100% adaptada a dispositivos móviles.

---

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3 moderno (*Glassmorphism*, variables CSS, animaciones), JavaScript Vanilla (ESModules).
- **Base de Datos:** Cloud Firestore (Firebase Web SDK v10).
- **Alojamiento:** Vercel (Sitio estático de alto rendimiento).
